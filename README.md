A project containing multiple Unity systems that can be easily added into other Unity projects/games. Each system is easy to add, modular, and is made to not break other scripts.


> **PLEASE NOTE**
> 
> This project is not a game or anything like that, so please do not view it as such. The project is a collection of systems. The demo link contains demos for systems.
> 
> Demos are not polished. They are only meant as a simple way to understand what each system does. The sytems themselves are carefully made to be modular, and not interfere with other scripts in an existing project.

**Demo Link:** [Itch.io Link](https://starcoder.itch.io/ultimate-unity-systems)

## Features
Some main features

 - Contains 6 different systems
 - Each system is highly modular and customizable
 - Contains a General folder that includes smaller systems
 - Each system is organized into seperate folders, to make it easy for people to add what they need

## Overview
This project was started as a place where I could create Unity systems, that could be used by me for later projects, or for others. It contains multiple, like a simple health bar, a custom cursor, or a custom ammo counter(my favorite).

Unfortunately, I haven't been able to work on this project much, hence why the Not So Ultimate subtitle. It contains 6 systems, each one ready to use in other projects.

---

## Systems

**Custom Ammo Counter** - A custom curved ammo counter that goes around your crosshair. There are many ways to customize this, including color, alpha values, radius, angles, thickness, etc.
**Status Effect System** - A modular status effect system that uses Scriptable Objects to easily create new effects
**Custom Cursor** - A custom cursor that is easily customizable, and includes an option for text.
**Simple Health System** - A simple health system meant for quick prototypes, being customizable to test different ideas out, while not being too complex
**Mouse Hover System** - A system to detect when your mouse is hovering over an object
**Interaction System** - An interaction system to interact with objects, like a door for example.
